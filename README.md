## Rules
- Preserve the original BANGLADESH BHASHA project.
- Keep the existing BD INTERNATIONAL NEWS website intact.
- All new application logic must be written in BBH.
- Do not use Java, Kotlin or Python as substitute implementation languages.
- Android system interoperability must be developed through BBH runtime support.
- Back up before every modification.
- Test each stage before proceeding.
- Never include credentials or private data in Git.
